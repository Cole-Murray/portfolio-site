## Product intent

Build a personal portfolio website that:

- Displays **work experience**, **projects**, and **interests**
- Feels **professional yet personal** — personality without gimmicks
- Is **modern**, follows current web best practices, and uses **tasteful** themes and small animations
- Impresses technical visitors **without being overly engineered**
- Prioritizes an **MVP shipped and deployed ASAP**; deeper impressiveness can wait

## Success criteria (MVP)

A visitor can, within ~30–60 seconds:

1. Understand who Cole is and what he studies / cares about
2. See credible evidence of skill via projects and experience
3. Contact him or find LinkedIn / GitHub / resume links
4. Experience a polished, responsive layout that works on phone and desktop

## Non-goals (for now)

- CMS / admin / blog platform
- Auth, databases, or backend APIs beyond static/contact needs
- Heavy 3D / WebGL showpieces (Three.js skills exist for later if desired)
- Perfect pixel craft or Awwwards-level motion before content and deploy exist

## Tone & personality notes

Capture specifics over time. Starting defaults:

- Competent, curious, approachable — not corporate-stiff, not meme-casual
- Engineering credibility over visual spectacle
- Small, intentional motion > constant animation noise

## Settled decisions

- **Layout:** Single scrolling page with section anchors. Nav bar desired later; defer implementation details until build time.
- **Aesthetic:** Dark modern (white type on deep gray-blue). Primary visual north star: jesseermens.nl. See [DESIGN.md](DESIGN.md).
- **Experience hierarchy:** Large “second hero” for most recent summer internship; smaller blocks for earlier work (Martinez-inspired).
- **Motion:** Simple spins + smooth scroll reveals; no ambitious cinematic 3D scroll spectacles for MVP.
